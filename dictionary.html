흔히 쓰는 분포는 서로 남남이 아닙니다. 한 분포의 특수한 경우이거나, 변수를 바꿔 얻었거나, 표본이 커질 때 다가가는 극한입니다. 3D 지도에서 분포 이름표를 누르면 연결된 길이 밝아지고, 아래 사전 카드에 식·용도·파이썬 호출법·생성 AI 프롬프트가 나옵니다.

관계 요약표

지도의 화살표를 한 줄씩 풀었습니다. 실선은 정확히 성립하는 변환이나 특수 경우, 점선은 조건이 극한으로 갈 때 성립하는 근사입니다. 분포 이름을 누르면 사전 카드로 갑니다.

원 그림을 읽을 때 고칠 점

이 사전의 바탕이 된 인포그래픽(matharium)은 관계를 한눈에 보여 주지만, 몇 군데 화살표 방향과 조건이 어긋나 있습니다. 강의 자료로 옮길 때는 아래처럼 고쳐 쓰세요. 각 항목은 아래 파이썬 검증 코드로 직접 확인할 수 있습니다.

  1. 지수 → 라플라스: 그림의 |X₁ − X₂|는 다시 지수분포가 됩니다(무기억성). 라플라스는 절댓값 없는 차 X₁ − X₂입니다.
  2. 코시 화살표 방향: 표준정규 둘의 비 Z₁/Z₂가 코시입니다. 그림은 코시에서 표준정규로 그려져 있어 방향이 반대입니다.
  3. 코시 밀도식: 바른 식은 f(x) = 1 / (πγ[1 + ((x − x₀)/γ)²]) 입니다.
  4. 카이제곱 ↔ 감마의 “ν = 2r”: 비율 λ = ½일 때만 성립합니다. χ²(ν) = Gamma(r = ν/2, λ = ½).
  5. 스튜던트 t가 빠짐: 검정에서 가장 많이 쓰는 분포입니다. t = Z / √(χ²_ν/ν), t(1) = 코시, t² ~ F(1, ν), ν → ∞이면 Z. 이 사전에 보충했습니다.
  6. 지수 → 와이불의 “k = γ”: 정확히는 E ~ Exp(1)일 때 λ·E^(1/k) ~ Weibull(k, λ)이고, k = 1이면 지수 그대로입니다.
  7. 음이항 → 포아송: n → ∞만으로는 부족합니다. r(1 − p) = λ를 고정하려면 p → 1이 함께 가야 합니다.
  8. 기하와 음이항의 기준: 그림의 기하는 “시행 수”(1, 2, …), 음이항은 “실패 수”(0, 1, …)로 셉니다. r = 1 음이항은 기하에서 1을 뺀 값입니다. scipy도 같은 기준입니다.
  9. 초기하 표기: 그림의 (M, N, K)와 scipy의 hypergeom(M, n, N)은 글자 뜻이 다릅니다. 아래 파이썬 표를 보세요.

파이썬으로 부르기

scipy.stats의 분포는 모두 같은 틀을 씁니다. 매개변수를 넣어 고정된 분포 객체를 만든 뒤 메서드를 부릅니다. 이산 분포는 pmf, 연속 분포는 pdf를 씁니다.

from scipy import stats
import numpy as np

X = stats.norm(loc=0, scale=1)   # 분포 객체 만들기 (loc=위치, scale=척도)

X.pdf(1.0)        # 밀도 (이산 분포는 X.pmf(k))
X.cdf(1.96)       # 누적확률 P(X ≤ x)
X.sf(1.96)        # 꼬리확률 P(X > x) = 1 − cdf, 단측 p-값
X.ppf(0.975)      # 분위수 (cdf의 역함수) → 1.959…
X.mean(), X.var(), X.interval(0.95)
X.rvs(size=1000, random_state=42)   # 난수 뽑기

# 자료에 맞추기 (연속 분포)
data = stats.gamma(a=2, scale=3).rvs(500, random_state=1)
a, loc, scale = stats.gamma.fit(data, floc=0)   # loc 고정이 보통 안전

교과서 표기 → scipy 매개변수

생성 AI가 가장 자주 틀리는 부분입니다. 특히 지수·감마는 비율 λ가 아니라 척도 scale = 1/λ를 받습니다.

관계 검증 실험

지도의 화살표를 난수로 직접 확인합니다. 콜모고로프-스미르노프(KS) 검정의 p-값이 0.01보다 크면 “목표 분포와 다르다고 볼 근거가 없다”는 뜻입니다. 코시처럼 꼬리가 두꺼운 경우는 실행마다 p-값이 크게 흔들립니다.

import numpy as np
from scipy import stats
rng = np.random.default_rng(42)
N = 200_000

# 1) 표준정규 둘의 비 → 코시
z1, z2 = rng.standard_normal((2, N))
print("Z1/Z2 ~ Cauchy      ", stats.kstest(z1 / z2, "cauchy").pvalue)

# 2) 표준정규 제곱 4개의 합 → χ²(4)
q = (rng.standard_normal((N, 4)) ** 2).sum(axis=1)
print("ΣZ² ~ χ²(4)         ", stats.kstest(q, "chi2", args=(4,)).pvalue)

# 3) Z / √(χ²/ν) → t(ν),  t² → F(1, ν)
c = rng.chisquare(9, N)
t = rng.standard_normal(N) / np.sqrt(c / 9)
print("t(9)                ", stats.kstest(t, "t", args=(9,)).pvalue)
print("t² ~ F(1, 9)        ", stats.kstest(t**2, "f", args=(1, 9)).pvalue)

# 4) 지수 둘의 차 → 라플라스, 차의 절댓값 → 다시 지수
e1, e2 = rng.exponential(1.0, (2, N))
print("E1−E2 ~ Laplace     ", stats.kstest(e1 - e2, "laplace").pvalue)
print("|E1−E2| ~ Exp       ", stats.kstest(np.abs(e1 - e2), "expon").pvalue)

# 5) −ln U → 지수 (역변환 표집)
u = rng.uniform(size=N)
print("−ln U ~ Exp(1)      ", stats.kstest(-np.log(u), "expon").pvalue)

# 6) 감마 비율 → 베타
x, y = rng.gamma(2, 1, N), rng.gamma(5, 1, N)
print("X/(X+Y) ~ Beta(2,5) ", stats.kstest(x / (x + y), "beta", args=(2, 5)).pvalue)

# 7) 이항(1000, 0.004) ≈ 포아송(4): pmf 최대 차이
k = np.arange(15)
gap = np.abs(stats.binom.pmf(k, 1000, 0.004) - stats.poisson.pmf(k, 4)).max()
print("max |Bin − Poi|     ", gap)   # 약 0.0004

scipy 1.18.1에서 실행해 확인했습니다. 코시 항목만 p ≈ 0.03으로 낮게 나왔고, 다른 시드로 돌리면 크게 달라집니다.

생성 AI 프롬프트 작성법

“이 데이터 무슨 분포야?”라고만 물으면 AI는 정규분포부터 꺼냅니다. 분포는 모양보다 자료가 만들어진 이야기로 고르는 것이 맞습니다. 그 이야기를 프롬프트에 먼저 써 주세요.

1 · 역할과 독자누가 읽을 결과인지 (강의용, 보고서용, 코드만)
2 · 자료의 생성 이야기셌는가 쟀는가, 단위, 범위(0 이상? 0~1?), 독립인가
3 · 후보와 이유후보 2~3개를 지도 위 관계와 함께 설명하게 함
4 · 검증 요구평균·분산 비교, QQ 플롯, AIC, scipy 모수화 표를 먼저
5 · 출력 형식코드와 해석을 나누고 길이를 정함

기본 틀

너는 통계 분석가야. 결과는 [비전공 관리자 / 수강생]이 읽어.

[자료 이야기]
- 무엇을: [하루 콜센터 접수 건수 / 수리 완료까지 걸린 시간 …]
- 셌는가 쟀는가: [정수 건수 / 연속 시간(분)]
- 범위: [0 이상, 상한 없음]
- 독립성: [날짜끼리 독립이라고 가정 / 요일 효과 있음]

[요청]
1. 후보 분포 2~3개와, 각각이 위 이야기와 맞는 이유
2. 후보 사이 관계(특수 경우·극한)를 한 줄씩
3. scipy.stats 매개변수 표를 먼저 쓰고 (특히 scale = 1/λ 여부)
4. 적합 코드, QQ 플롯, AIC 비교
5. 결론은 3줄, 가정이 깨질 때의 대안 1개

모르는 값은 지어내지 말고 질문으로 남겨 줘.

자주 틀리는 것을 미리 막는 줄

  • “지수·감마는 rate인지 scale인지 표로 밝혀 줘.”
  • “기하분포가 1부터 세는지 0부터 세는지 적어 줘.”
  • “hypergeom(M, n, N) 인자의 뜻을 우리 문제의 숫자로 대입해 보여 줘.”
  • “lognorm은 s=σ, scale=e^μ로 써 줘.”
  • “평균과 분산이 크게 다르면 포아송 대신 음이항을 검토해 줘.”
  • “정규 근사를 쓰면 근사가 괜찮은 조건(np ≥ 10 등)을 함께 써 줘.”

각 분포 카드에 그 분포에 맞춘 프롬프트 예가 있습니다. 프롬프트 설계 전반은 생성형 AI 활용 전략 해설에서 이어집니다.

강의 준비용 예

통계학 입문 수강생용 10분 활동을 만들어 줘.
주제: 이항분포가 포아송과 정규로 다가가는 과정.
- n = 10, 50, 500일 때 p = 0.01, 0.3 두 경우를 표로
- 각 경우 어느 근사가 나은지 학생이 맞히는 퀴즈 4문항 (정답·해설 포함)
- 확인용 파이썬 코드 (scipy.stats.binom, poisson, norm만 사용, 20줄 이내)
- 근사 조건(np, n(1−p))은 숫자로 보여 주고 외우라고 하지 말 것
